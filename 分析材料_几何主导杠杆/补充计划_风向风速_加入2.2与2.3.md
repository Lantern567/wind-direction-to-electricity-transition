## 0. 命题红线（先钉死，防止跑偏）

风向、风速都是规划者**不可控的外生背景**。本补充的每一条结论都必须落到——
**"给定风资源，几何是可控主杠杆"**，绝不能滑向"风速 > 几何"的方差叙事。
所有风速段落须与 §2.2 已写入的 Sobol 框架一致：**方差解释力 ≠ 可控性**；
风速年际波动再大，也是"外生噪声"，而非可回收价值。

## 2. §2.2 要加的分析：风向 × 几何 → 尾流（"给定风向，几何主导"）

**A1〔Tier 1，n=72〕尾流的三因联合归因 WakeLoss ~ WCI + AxisMismatch + spacing_d。**
- 做法：偏相关 / 分层回归；核心图 = 散点 x=`AxisMismatch`、y=`WakeLoss`，按 `WCI` 分色（或"集中玫瑰 vs 宽玫瑰"两组分别拟合）。
- 预期讯息：**风向越集中（高 WCI），排布错位（高 mismatch）与过密（低 spacing）的代价越大** → 在给定风向下，尾流由几何决定。
- ⚠️ 框架注意：`AxisMismatch` 在此是**解释/方差侧**变量（与 Sobol 里"失配敏感度高"一致）。必须显式写明其与 §2.3 的张力：
  "**截面上失配↔高尾流，但把阵列旋回最优只回收 ~1%（§2.3）——因为高失配的场多是受海域约束、无法自由转向的场。**"
  即：A1 交代风向背景与相关性，把"能不能回收"这个可控性问题**主动交棒给 §2.3**。

**A2〔Tier 2〕代表场的尾流风向各向异性。**
- 对 3–4 个代表场（密排 A / 受约束 B / 宽玫瑰场），按风向扇区分解尾流损失并叠加风玫瑰。
- 讯息：主风扇区正砸在密排行轴上 → 尾流是"风向 × 几何"的交互，而非孤立的风或孤立的排布。
- 无 Tier 2 时可降级为 1 个示意图 + 定性描述。

## 3. §2.3 要加的分析：风向宽窄 + 风速波动 → 朝向为何弱

**B1〔Tier 1，n=72〕朝向收益 ~ 风向集中度：orientation_gain ~ WCI。**
- 图 = 散点 x=`WCI`、y=每场平均 `gain_pct`；预期正相关但**峰值仍小**。
- 讯息（+0.9% 的机制）：**真实海上风玫瑰偏宽（中位 WCI 仅 0.25），单一最优朝向无处发力**；即便最集中的场，可回收也有限。这把"朝向弱"从现象讲成机制。

**B2〔Tier 2〕朝向敏感曲线的平坦度。**
- 从 S1 的 18 角度扫描算每场"**朝向弹性**" = (AEP_max − AEP_min)/AEP_mean；分布 + 与 WCI 相关。
- 讯息：多数场曲线很平（弹性小）→ 旋转天花板本就低；弹性与 WCI 正相关，印证 B1。

**B3〔Tier 1〕真实风速变化分析（用户明确想要的一块）。**
- (a) **风速水平**：逐场风速/风功率分布（`WPD_hist` 与 `CF` 代理），示 171 场的资源梯度。
- (b) **年际风速波动 vs 三杠杆**：CF 年际 CV 中位 ≈ 4.9% —— **比朝向杠杆（+0.9%）还大，却完全不可控**；
  对照几何（+6~12%）→ 讯息："等一个好风年"能带来 ~5% 的摆动但不可控，**几何是唯一能稳定压过'风年噪声'的可控杠杆**。这条直接强化 §2.3 图3d 的"排布 ≫ 年际"。
- (c) **控风速后密度仍主导尾流**：`WakeLoss ~ spacing_d`，把风速（CF 或 WPD）作协变量的偏相关。
  用途：回应审稿人可能的反驳"高 CF 高尾流会不会只是风速的锅？"——证明**控住风速后，密度对尾流的负相关仍显著**，守住 §2.2。

## 5. 风险 / caveat（须在正文/局限里如实写）

1. **n=72**：WCI/WPD/主向仅覆盖 72 场。Tier-1 结论先作 72 场子样 POC；全 171 覆盖需廷显把风资源提取扩到全样本（或把 ERA5 传来本机）。
2. **WCI 基于 1981–2010 气候态**：风向气候态稳定，与 2014–2024 尾流关联可接受；严格版应重算真实期 WCI（Tier 2）。
3. **命题红线**：风速段落必须落到"外生噪声 vs 可控杠杆"，不得反噬"几何主导"。
4. **变量同源**：`theta_energy/AxisMismatch` 与 §2.3 朝向变量同源，A1 与 §2.3 口径须统一，避免自相矛盾（已在 A1 备注处理）。
