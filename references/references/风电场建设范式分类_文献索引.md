# 风电场建设范式分类 — 参考文献索引

> 创建日期: 2026-07-03
> 用途: 任务一建设范式分类（P_A ~ P_E）阈值修订的文献依据

---

## 已下载文献

### 1. Shen & Mikkelsen (2011) — DTU 风机排列间距研究
- **文件**: `Shen_Mikkelsen_2011_DTU_Offshore_Turbine_Arrangement.pdf`
- **来源**: DTU Orbit (Technical University of Denmark)
- **核心发现**: LES 模拟显示 7D 间距时下游风机功率恢复至来流~50%，建议海上风场至少 7D 间距
- **阈值依据**: **P_E 大间距 → SpacingD > 7D**

### 2. Meyers & Meneveau (2012) — 超大电场最优间距
- **文件**: `Meyers_Meneveau_2012_Optimal_Spacing_Wind_Farms.pdf`
- **来源**: Wind Energy, Vol. 15, pp. 305–317 (arXiv:1111.2296)
- **核心发现**: 计入土地成本后超大电场（>30km）最优间距 12-15D，远大于行业常规 6-10D
- **阈值依据**: 验证 7D 作为"典型间距"上限的合理性；12D+ 为"超疏间距"

### 3. Rasiński & Malecha (2025) — 波兰海上风场尾流损失与经济分析
- **文件**: `Rasinski_Malecha_2025_Wake_Losses_Polish_OWF.pdf`
- **来源**: Energies (MDPI), 2025, 18, 4190 (Open Access)
- **核心发现**: 测试 5D/8D/10D 间距，尾流损失 16.5-38%，5D 时损失最严重
- **阈值依据**: 5D 为密集下限，验证 5D < SpacingD ≤ 7D 为"典型"的合理性

## 未下载但已引用的文献（需通过机构访问获取）

### 4. Jung & Schindler (2023) — 全球海上风机队属性
- **DOI**: 10.1016/j.rser.2023.113667
- **期刊**: Renewable and Sustainable Energy Reviews, Vol. 186, 113667
- **核心发现**: 全球 8,877 台风机中位间距 5.1D（归一化到叶轮直径）
- **阈值依据**: 全球实证基准 — 验证本数据集中位 3.5D 偏低

### 5. Barthelmie et al. (2010) — Horns Rev vs Nysted 尾流对比
- **DOI**: 10.1175/2010JTECHA1398.1
- **期刊**: J. Atmos. Oceanic Technol., 27: 1302–1317
- **核心发现**: Horns Rev (7D) 与 Nysted (10.5D) 尾流损失差异在统计上不显著
- **阈值依据**: 7-10D 为海上风场常见间距范围

### 6. Stevens et al. (2016) — 经济+流体最优间距
- **DOI**: 10.1002/we.2016
- **期刊**: Wind Energy, Vol. 20, pp. 465–477 (Open Access via Wiley)
- **核心发现**: 计入电缆/维护成本后最优间距略降但仍大于常规实践

## 风资源分级标准

### NREL Wind Resource Classification (50m高度)
| 等级 | WPD (W/m²) | 描述 |
|------|-----------|------|
| Class 1 | 0–200 | Poor |
| Class 2 | 200–300 | Marginal |
| Class 3 | 300–400 | Fair |
| Class 4 | 400–500 | Good |
| Class 5 | **500–600** | **Excellent** ← P_D 阈值 |
| Class 6 | 600–800 | Outstanding |
| Class 7 | >800 | Superb |

### 圆形统计 WCI 分级
| WCI | 风向集中度 |
|-----|-----------|
| 0.0–0.2 | 分散（无明显主导方向） |
| 0.2–0.3 | 弱集中 |
| **0.3–0.5** | **中等集中** ← P_A 阈值下限 |
| 0.5–0.7 | 高度集中 |
| >0.7 | 极强主导方向 |

## 修订后的范式分类阈值

| 范式 | 旧方法 | 新方法 | 文献依据 |
|------|--------|--------|---------|
| P_A 横风向 | `WCI > median` | `WCI_hist > 0.3` | 圆形统计分类 |
| P_B 约束 | `area < median` | `depth < 20m` 或 `area < 10 km²` | 单桩极限水深+分布下四分位 |
| P_D 高WPD | `WPD > 75th` | `WPD_hist > 500 W/m²` | NREL Class 5 Excellent |
| P_E 大间距 | `SpacingD > median` | `SpacingD > 7.0 D` | Shen & Mikkelsen (2011) DTU |
