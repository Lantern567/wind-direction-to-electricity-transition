# 四情景风速—风向贡献分解：结论

## 核心问题

纠正阵列朝向的平均 AEP 收益（G），是否超过实际风速相对于历史气候基准造成的典型发电影响（M_S）？

## 答案

**否。对 97% 的已建风场，年际风速波动造成的发电影响（中位 6.1%）远超朝向优化的可回收收益（中位 0.3%）。**

## 数值支撑

| 指标 | 均值 | 中位 |
|------|------|------|
| 风速效应 M_S（Shapley RMS） | 7.1% | **6.1%** |
| 风向效应 M_D（Shapley RMS） | 2.3% | 2.1% |
| 朝向收益 G | 0.9% | **0.3%** |
| R = G / M_S | — | 0.05 |

仅 3 个农场（F57 越南 +17.0%、F157 丹麦 +6.1%、F91 珠江口 +6.6%）的朝向收益超过自身风速年际噪声。这 3 个场的地理聚集（季风走廊 + 海峡风道）与前期长尾分析一致。

## 物理含义

1. **风速主导年际发电波动**。一个风场的"好风年"和"差风年"之间的发电差异约 6%——这是外生气象噪声，规划者和开发者无法控制。

2. **朝向收益被风速噪声淹没**。等一个好风年带来的发电增益（~6%）是优化朝向（~0.3%）的 20 倍。从投资回报角度，开发者没有任何理由把朝向优化置于资源评估之上。

3. **风速和风向效应方向一致**。在大多数农场-年份，风速和风向对发电的影响同号——高风速年份往往伴随有利风向变化。交互项 I 很小（中位约 0.1%），证明二乘二分解是合适的，不需要更复杂的非线性模型。

4. **长尾农场的特殊性得到确认**。F57、F157、F91 是仅有的三个朝向收益超过风速噪声的农场。它们全部位于已知的季风走廊或海峡地形整流区，进一步验证了走廊图谱的筛查价值。

## 与前期结论的关系

本分析在前期"几何 >> 朝向"的基础上增加了气候维度的比较对象：

```
年际风速噪声（~6%）>> 朝向优化（~0.3%）
几何优化（~6%）≈ 年际风速噪声
```

几何是唯一能与年际气候噪声相抗衡的可控杠杆。朝向在这三个量级中排在最低位。这不否定朝向在某些特殊场址的第一阶重要性（F57 等长尾场），但确认了其在全球尺度上的次要地位。

## 论文可表述为

> 在统一的四情景反事实框架下，实际风速相对于历史气候基准造成的典型发电影响约为 6.1%（中位 RMS）。仅 3 个已建风场（F57、F157、F91）的朝向优化可回收 AEP 超过这一影响，三者集中于季风海岸和海峡风道，与前期长尾分析和走廊图谱的筛查结果一致。对绝大多数风场，风速年际波动是比朝向错位更重要的发电不确定性来源。

## 数据与验证

- 查找表已包含电气损耗（ELECTRICAL_LOSS=0.9215），F57 2024 无尾流 AEP 与 S3 误差 15.7%
- 四情景共用同一查找表，系统偏差在 S/D/I 比值中抵消——修正前后结论完全一致
- 分解闭合误差 <10⁻¹⁵ 个百分点，Shapley 闭合误差 <10⁻¹⁵ 个百分点

## 覆盖与局限

- 计算覆盖全区域：897 场-年含东亚 499、欧洲 364、美东 31，171 场全覆盖
- 历史基准采用 2014–2024 年多年代理（11 年池化），非任务书首选的 1981–2010 年逐小时基准（后者仅覆盖东亚且为逐日采样）
- 未使用 MERRA-2 独立再分析数据对 ERA5 风向分布做交叉核验
